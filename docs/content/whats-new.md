## Version 1.0.0

Initial release of Simple Fasting.

- Start and track active fasts with elapsed or remaining time.
- Save completed fasts locally on your device.
- Review fasting history and statistics.
- Create reusable fasting goals and custom fast durations.
- Add optional notes to fasts.
- Use local fast-end and daily reminder notifications.
- See fasting progress in supported widgets and iOS Live Activities.
- Export and import fasting history with JSON or CSV files.
- Personalize the app with theme, accent color, and display-format settings.
- Keep fasting data local with no account, no ads, and no analytics tracking.
