# Future Scope

There is no active feature roadmap after Version 1. The product should remain a
small, local fasting tracker.

## Maintenance scope

- Fix correctness, security, privacy, accessibility, and platform compatibility
  issues.
- Keep iOS, Android, Expo, widgets, notifications, and store requirements
  working.
- Improve performance or clarity only when there is a measured problem.
- Keep legal, FAQ, store, and website copy accurate.

## Not planned

- Accounts, registration, login, profiles, or cloud recovery.
- Cloud synchronization, backend APIs, or remote databases.
- Payments, subscriptions, premium tiers, donations, or advertising.
- Analytics SDKs, product tracking, installation identifiers, or profiling.
- Health-platform integrations, social features, AI health advice, or complex
  meal tracking.
- Additional charts, gamification, or widget variants without demonstrated
  demand.

Any future change to these boundaries requires an explicit product decision,
privacy review, documentation update, and a new tested release. It must never
silently upload existing local fasting data.
