# Simple Fasting

Privacy-first, offline-first fasting tracker with no account, backend, analytics, ads, or subscription.

- `app/` — Expo React Native application for iOS and Android.
- `www/` — static Astro website.
- `docs/` — product specification, execution plan, release guide, and roadmap.

Current development is focused on the mobile application. Start with [`app/README.md`](app/README.md) for setup and commands, and [`docs/01-product-specification.md`](docs/01-product-specification.md) for product behavior.
